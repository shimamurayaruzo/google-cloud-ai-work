# 「いつもと違う」の判定基準 v2（MVP の3体験に限定）

作成：2026-09-27 杉浦（案）
対象：見守りエージェント企画書（改訂 2026-09-22）の MVP 3体験と自己修復。
9/27 の試作5パターンと構成図に合わせてある。
範囲外：介護一般の異常基準。
ここで扱わないものは「人に戻す」に落とす。
凡例：[企画書] は方針が企画書にあることを示す。
回数・時間・レベル・文面の具体化は、別記が無くてもすべて [推測]（初期値）。
★は決めどころで、推奨案を付けてある。
根拠：観察の語彙は要介護認定の認定調査項目、救急への引継ぎは消防庁の資料、人に戻す境界は医師法等に合わせた。
出典と逐語は「根拠資料 v1」。

---

## 0. 設計の前提

- 判定は3層に分ける。
  回数・時刻・予定との照合・キーワードはコードで決め、発話の意味は Gemini に「評価対象のデータ」として渡して確信度付きで返させ、確信度が低いもの・医療的なもの・外部への共有は人に戻す。
  [企画書 設計原則]
- 診断をしない。
  病名・評価票の項目番号・点数を出力しない。
  記録を並べて「ご確認ください」で止める。
  [企画書 HITL／[R4](rationale.md#r4)]
- 本人の返答だけで断定しない。
  記録は「本人がそう答えた」ことであって、実際にできたことではない。
  [企画書 差別化表]
- 観察の語彙は要介護認定の認定調査項目（食事摂取・上衣の着脱・薬の内服・しつこく同じ話をする・ひどい物忘れ・感情が不安定）に寄せる。
  [R2-1](rationale.md#r2-1)
- 認知機能の評価票は専門職が採点するものなので使わない。
  [R2-2](rationale.md#r2-2)
- 意識レベルの判定はしない。
  渡すのは「最後に普段どおり話した時刻と内容」と「その後の声かけへの返事の有無と時刻」だけ。
  [R3-2](rationale.md#r3-2)・[R3-5](rationale.md#r3-5)
- 本人に、記録すること・家族に送ること・医師等へは家族が決めて共有することを初回に説明し、同意を確認する。
  [R4-4](rationale.md#r4-4)
- 発話に紛れた指示に従わないため、発話は「評価対象のデータ」として括って渡す。
  [推測／評価セット T4 の応用]
- テレビや来訪者の声を本人と区別する方法は未確認で、区別できないものは「本人か分からない（unclear）」として何も決めつけない。
  [9/27 試作と同じ]

## 0-2. 9/27 の試作との対応

| 試作の動き | この基準での位置 |
|---|---|
| 「まだ」→15分後に再確認を予約 | 3-1。L0 |
| 「着替えたよ」→記録 | 3-1。L0 |
| 「疲れた。ちょっと腰が痛いの」→家族へ緊急通知（根拠の発話付き）、医療判断はしない | 3-2 の痛みの訴え。この基準では L3（即時通知・確認依頼）。L4 は転倒・動けない等に限る |
| テレビの音→unclear と記録、何も決めつけない | 2 の C 層 |
| 「妹に電話してちょうだい」→自分では電話せず家族へ「頼まれました」 | 3-5。本人に断ってから |
| 家族画面「医師に共有して」承認なし→止まる | 企画書 HITL「承認後」。加えて本人への確認を挟む（4-4） |

構成図の「確認した」ボタンで段階上げが止まる仕組みは、L3→L4 の段階上げの停止条件としてそのまま使う。
「確認した」に「誤報だった」の選択肢を足すと、4 節の誤検知の記録になる。

## 1. 通知レベル（5段階）

| レベル | 名前 | 誰に・いつ | 企画書の対応行 |
|---|---|---|---|
| L0 | 記録のみ | 構造化記録に残す。通知しない | 自動 |
| L1 | 夕方レポート | 18:00 の「今日の様子」に載せる | 自動（日次要約） |
| L2 | お知らせ | 家族へ通知する。根拠を添える。返信は求めない | 自動（家族への注意通知） |
| L3 | 確認のお願い | 家族へ即通知する。「家の電話にかけてみてください」等の具体的な行動を1つ書く。根拠を添える | 自動＋根拠 |
| L4 | 至急 | 家族へ即通知し、電話を促す。本人には定型文を1回伝え、以後は質問をせず、3分ごとに安心の一文だけを流す。家族の「確認した」で止まる | 自動＋根拠（連続無反応・転倒）。定型文・安心文・3分は推測 |

★ L4 の通知文で 119 番に触れるか。
推奨：発話由来の L4（転んだ・動けない等）では「必要と思われたら 119 番へ」を書く。
無反応由来の L4 では書かず、「家の電話→iPad の通話→近くの人」を先に置く。
理由：発話由来は消防庁の「転倒で強い衝撃を受けた」等に当たり、家族に電話だけ促して 119 の選択肢を示さないのは遅れの原因になる。
無反応は昼寝・入浴・難聴でも起きるので、119 に直結させると誤通報と施錠された家への突入を招く。

## 2. 判定の三層

| 層 | 判定するもの | 方法 | 例 |
|---|---|---|---|
| A 決定論（コード） | 回数・時刻・予定との照合・キーワードの有無・質問の内容カテゴリの一致 | ルール。LLM を使わない | 無反応が2回連続した／予定表に「デイサービス」がある／質問カテゴリ「曜日」が同じ |
| B 文脈（LLM） | 発話の意味・気分・質問の内容カテゴリへの分類 | Gemini に発話を「データ」として渡し、JSON で返させる。確信度を付ける | 「腰が痛い」が訴えか世間話か／「ご飯まだ」は食事カテゴリ |
| C 人 | 確信度が低いもの、医療的なもの、外部共有、本人か分からない音声 | 家族へ戻す、または何もしない | 診断・救急・医師への共有・テレビの音 |

- 質問の同一性は B 層が付けた内容カテゴリ（日付・曜日／時刻／予定／食事／人／場所／その他）が同じなら同一とみなす。
  [推測]
- 声かけへの返答として拾ったもの以外（声かけの時間外の音声、本人以外の可能性がある音声）は保存せず、家族にも送らない。
  本人の私的な会話が家族に渡らないようにするため。
  [推測]

★ B 層の確信度の閾値。
推奨：0.7 未満は「判定未確定」とする。
ただし痛み・転倒など即時通知の対象になりうる発話は、夕方送りにせず、判定未確定であることと根拠を添えて家族へ即時に確認を求める。
それ以外の低確信度の返答は夕方レポートの「判断できなかった返答」に原文で載せる。
理由：低い確信度で全部を即通知すると通知疲れになり、全部を夕方に回すと転倒を見逃す。

- 無反応は昼寝・入浴・庭・難聴・機器の故障でも起きる。
  無反応の L4 を 119 に直結させない。
  [救急救命士の視点]
- 家族の「確認した」で段階上げが止まる。
  [9/27 構成図]

★ 無反応の回数と時間。
推奨：2回目の声かけ（初回から15分後）が無反応で L3、3回目（初回から30分後）が無反応で L4。
各回の応答待ちは5分で、無反応の確定は応答待ちの終了時。
したがって L3 の確定は初回から20分、L4 の確定は初回から35分。
理由：1回は聞こえなかっただけの可能性が高い。
3回目の声かけ（初回から30分）と L4 の確定（35分）は、転倒後に長く床にいることを避ける目安として置いた運用値で、公的な根拠は無い。

★ 就寝時間帯の設定。
推奨：家族が設定する。
初期値は 21:00〜7:00。
夜間のトイレでの転倒は範囲外として明記する。

## 4. 誤検知の扱い

- 家族は通知に「受け取った」「確認した」「誤報だった」を付けられる。
  「受け取った」は既読の合図で段階上げは止まらない。
  「確認した」は本人と話せた、または状況を把握した合図で、段階上げと L4 後の安心文が止まる。
  誤報は記録に残し、閾値の見直し材料にする。
  [推測／「確認した」は 9/27 構成図]
- 閾値の変更は人が行う。
  [企画書 設計原則・HITL「設定変更は承認後」]
- 本人以外の声が混じりやすい時間帯（訪問介護など）は、家族が「除外時間」として設定できる。
  [推測]

★ 誤報が続いたときに閾値を自動で緩めるか。
推奨：緩めない。
人が変える。

## 6. 決めどころ（★のまとめ・杉浦の推奨案）

1. 119 番への言及 → 発話由来の L4 では「必要と思われたら 119 番へ」を書く。
   無反応由来では書かず、家の電話→iPad 通話→近くの人を先に置く。
2. LLM の確信度の閾値 → 0.7。
   即時通知の対象は未確定のまま即時に、それ以外は夕方へ。
3. 声かけの上限 → 合計3回（初回＋再確認2回）。
4. 予定が無い日の再確認間隔 → 30分。
5. L4 の語 → 群 A・B・C の初期値。
   家族が追加可。
   検知後に1問だけ確認。
6. 「痛い」のレベル → L3。
   痛みは3時間ほど後の声かけで一度聞き直す。
7. 無反応の回数 → 2回目（初回から15分後）が無反応で L3、3回目（30分後）が無反応で L4。
   応答待ちは各回5分。
8. 就寝時間帯 → 家族設定。
   初期値 21:00〜7:00。
9. 繰り返しの閾値 → 在宅日1日の合計。
   中央値＋3回かつ1.5倍・2日連続で L2。
   前日比2倍＋体調のサインで L3。
   最初の14日は基線。
10. 誤報での自動調整 → しない。
11. 1日の通知上限 → L2 のみ5件。
    L3・L4 は対象外。
12. 本人への説明と同意 → 初回設定時に iPad が説明し家族が同席。
    医師等への共有は前日の声かけで本人に一度聞く。
