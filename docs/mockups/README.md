## 見方

- エクスプローラーでファイルをダブルクリックすると、ブラウザで開きます。各ページの上に 4 枚を行き来するリンクがあります。
- 各ページの一番上の赤い枠が「決めどころ」です。印刷して「赤:」の欄に書き込むか、口頭でお伝えください。
- ①② は画面の上の「場面」ボタンで状態を切り替えます（このボタンは紙芝居用で、本番には付きません）。右の欄に、その場面で裏で起きていること（呼ぶ API、家族に届く LINE）を書いています。URL の末尾に `#6` のように番号を付けると、その場面から開きます。
- ③ は実際にタップできます（タブ、確認した／誤報だった、承認、居場所の入力、モード切替、今すぐ止める、要約の［番号］から会話を開く）。「表示幅」で PC 幅に切り替えると 2 列になります。`#plan` `#appr` `#ledger` `#settings` `#caps` でそのタブから開きます。
- ④ は合言葉に何を入れても通ります。「① 1 日分を再生する」で約 30 秒かけて 1 行ずつ流れます。`#menu` `#done` でその場面から開きます。

## 作っていて見つかったこと（赤入れの参考）

- **API に無いもの**: 居場所の登録（家族画面）、居場所の質問を声かけの時間外に受けて答える入口（端末）、寝室／お風呂のモード（両方）。決まったら docs/02 と src/api/README.md に先に足す。
- **段階の食い違い**: 腰の痛みは criteria 3-2 では L3、`eval/scenarios/dayservice-day.json` の期待値は `urgent`（④ の決めどころ 5）。
- **report-design.md 1 節の例文**: 日付が 10月8日（木）だが、デイは火・金。デイの日なのに 11:32・12:10 に在宅の記録がある（企画書 §10 のデモストーリー由来）。③ では例文をそのまま使い、直していない。
- **docs/03 §4 の夕方要約**: 「8:35 に着替えを確認」とあるが、台本では 8:35 は「まだ」、確認は 8:45。また「訴え」の語がある。④ の要約は「8:45 に『着替えたよ』とお返事」「とおっしゃいました」に直して描いた。
