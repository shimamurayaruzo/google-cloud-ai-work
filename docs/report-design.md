# ご家族向けレポートと引継ぎの設計 v2

作成：2026-09-27 杉浦（案）
対象：企画書の「夕方 一日を要約し根拠を添える」「異常時 家族へ即通知」「外部共有 医師・ケアマネ向け要約」の3種に、救急への引継ぎ（救急カード・現場の画面・救急隊向け表示）と本人への説明を加えた。
凡例：[企画書] は方針が企画書にあることを示す。
型・文面・例の数値はすべて [推測]。
例の時刻や集計値は架空のサンプル。
★は決めどころで、推奨案を付けてある。
根拠：語彙は要介護認定の認定調査項目、救急への引継ぎの順番は消防庁の資料、共有は個人情報保護法と意思決定支援ガイドラインに合わせた。
出典と逐語は「根拠資料 v1」。

---

## 0. 設計原則

- 1枚目だけ渡された人が判断できるか、を基準に紙面を組む。
  [杉浦の経験（都知事杯）]
- 断定しない。
  「〜のようです」「ご確認ください」で止め、判断は家族に返す。
  [企画書 HITL]
- すべての記録は「本人がそう答えた」記録で、実際にできたかは確認していない。
  出力に必ず明示する。
  [企画書 差別化表]
- 根拠となった発話・状態を添える。
  [企画書] 時刻と原文を添えるのは、その具体化。
  [推測]
- 「昨日まで」との比較を入れる。
  [企画書「単発通知から変化検知へ」]
- 医療診断をしない。
  [企画書] 病名・評価票の項目番号・点数を書かない。
  [R4-3](rationale.md#r4-3)
- 家族向けは会話調。
  「おっしゃいました」「お返事がありました」を使い、「発言」「訴え」「発話」は使わない。
  [推測]
- 免責（「体調や病気の判断は含みません」）は夕方レポートの末尾に1回だけ。
  即時通知では、何が分からないかを具体的に書く。
  [推測]
- LINE で読まれる前提で、最初の3行で結論が分かるようにする。
  [推測]
- 住所・持病・薬は認証のある画面にだけ保存・表示し、LINE の通知本文には載せない。
  例外は家の iPad の 119 画面（4 節）と救急隊向け表示（5 節）で、L4 の発生中か「119 にかけるとき」を開いたときだけ表示する。
  [推測]
  救急カードは初期設定で指定した1名にだけ送る。
  [R4-4](rationale.md#r4-4)

★ 文体。
推奨：です・ます調。
主語は「お母さま」等の続柄呼称にし、設定で変えられるようにする。

## 0-2. 本人への説明と同意

初回設定時に iPad が本人に伝え、家族が同席して同意を確認する。
[R4-4](rationale.md#r4-4) 意思決定支援ガイドライン

```
わたしは見守りのお手伝いをします。
お話しした内容は記録して、夕方に○○さんにお伝えします。
お医者さんやケアマネジャーさんに見せる前には、あなたに確認し、同意をいただいたうえで○○さんにも確認します。
やめてほしいときは、いつでも言ってください。
```

- 本人は自分の記録を iPad から聞ける。
  [推測]
- 医師・ケアマネへの共有は、家族の承認に加えて、共有の前日の声かけで本人に「明日、先生に最近の様子をお伝えしてもいいですか」と一度聞き、返答原文を記録に添える。
  [推測]

## 1. 夕方レポート（毎日 18:00・自動送信・L1）

### 型

（見出し）今日の様子 ○月○日（○）
（結論）1行。
「今日の記録には、確認をお願いする返答はありませんでした。」または「今日は1件、確認をお願いしたいことがあります。」
（お返事の記録）時刻つきの箇条書き。
着替え・食事・水分・薬の声かけへの返答。
（気になったこと）時刻と原文。
痛みは聞き直しの結果も書く。
無ければ「ありません」。
（お知らせの続き）日中の通知でまとめ送りにした分と、判断できなかった返答の原文。
無ければ「ありません」。
（昨日までとの比較）同じ質問の回数を内容ごとに、直近2週間と比べて1〜2行。
断定しない。
（この記録について）2文で固定。
「この記録は AI が声かけへのお返事から作っています。体調や病気の判断は含みません。」

### 企画書のデモストーリーで埋めた例（日付と 12:10・15:00 の行は架空）

今日の様子 10月8日（木）
結論：今日は1件、確認をお願いしたいことがあります。
お返事の記録
・9:15 の声かけに「着替えたよ」とお返事がありました（9:00 は「まだ」でしたので、10:00 のデイサービスに合わせて聞き直しました）。
・12:10 お昼ごはんの声かけに「食べたよ」とお返事がありました。
・15:00 お水の声かけにお返事がありました。
気になったこと
・11:32 「ちょっと腰が痛いの」とおっしゃいました。
　そのときにお知らせ済みです。
　15:00 に「腰はどうですか」と聞き直したところ「もう大丈夫」とのことでした。
お知らせの続き
・ありません。
昨日までとの比較
・同じ質問（「今日は何曜日」）は今日 6 回記録しました。
　本日はデイサービスの予定があるため、在宅日どうしの回数比較には含めていません。
この記録について
・この記録は AI が声かけへのお返事から作っています。
　体調や病気の判断は含みません。

★ 「結論」の1行を入れるか。
推奨：入れる。

★ 「気になったこと」が無い日の書き方。
推奨：「ありません」と明記する。

## 2. 即時通知

### L2（お知らせ、返信は求めない）

```
【お知らせ】
AI との会話の中で、同じ質問（「今日は何曜日」など）が、ここ 2 日は 1 日 6 回・7 回と、その前の 2 週間（1 日 2 回ほど）より増えています。
急に増えるときは、体調（水分・お通じ・眠り・お薬の変更）や、来客・暑さなどの影響のことがあります。
次にお会いするときに様子を見てください。
この通知への返信は不要です。
夕方の「今日の様子」にも載せます。
```

### L3（痛みなど本人の言葉から）

```
【確認をお願いします】11:32
お母さまが「ちょっと腰が痛いの」とおっしゃいました。
どの程度痛いか、動けるかは、AI からは分かりません。
お早めにお電話で声を聞いてください。
このあとも様子を聞き、3時間ほど後（15:00 ごろ）に一度「腰はどうですか」と聞き直してお知らせします。
救急車を呼ぶか迷うときの相談：#7119（○○県。携帯からは ○○-○○○○-○○○○）
```

- #7119 の行は、本人の住所の地域が実施地域のときだけ出す。
  未実施なら「かかりつけ ○○病院（電話○○）に相談」に置き換える。
  [R3-4](rationale.md#r3-4)

### L3（返事がないとき）

```
【確認をお願いします】9:20
9:00 と 9:15 の声かけに、お返事がありません。
家の電話（○○-○○○○-○○○○）にかけてみてください。
話せたら「確認した」を押してください。
次は 9:30 に最後の声かけをして、9:35 まで返事がなければ、あらためてお知らせします。
```

### L4（本人の言葉から、転んだ・動けない等）

```
【至急】14:05
14:05 の声かけに、お母さまが「転んだ」とおっしゃいました。
AI は「大丈夫ですか。ご家族に連絡します。そのまま動かずにお待ちください」と一度お伝えし、これ以上は質問をせず、3分ごとに「ご家族に連絡しました。無理に立ち上がらず、そのままお待ちください」とだけ伝えています。
声かけへのお返事として確認できた内容があれば、その言葉と時刻をこの通知に追記します。
お電話で声を聞いてください。
必要と思われたら 119 番へ。
「救急車を呼ぶ」を押すと、119 番で伝える順番のカードが開きます。
```

### L4（返事がないとき）

```
【至急】9:35
9:00 から 3 回の声かけに、お返事がありません。
まず①家の電話（○○）にかける ②iPad の通話ボタンで呼びかける（スピーカーから大きな音が出ます）
次に③近くの ○○さん（電話 ○○）に見に行ってもらう
それでも様子が分からないときは「救急車を呼ぶ」を押してください。
通報時に伝える内容をまとめた救急カードが開きます。
```

- 返事がないときは、昼寝・入浴・庭・補聴器なしでも起きるので、119 の前に3段階を置く。
  [救急救命士の視点]

★ L4 で 119 番に触れるか。
推奨：本人の言葉からの L4 では「必要と思われたら 119 番へ」。
返事がないときは 3 段階の後に「救急車を呼ぶ」ボタン。
基準 v2 と同じ。

## 3. 救急カード（家族が「救急車を呼ぶ」を押したときだけ開く）

- 遠隔の家族からの 119 は「第三者通報・状況不明」で、消防庁のプロトコルでは緊急（R3）として扱われる。
  だから「離れた場所から」「家に誰もいない」「呼吸や顔色は誰も見ていない」を最初に言う。
  [R3-2](rationale.md#r3-2)
- 「意識」という語は使わない。
  「意識なし」は消防庁のアルゴリズム図で心肺停止を疑う言葉に挙がり、現場に人がいないのに心肺蘇生の対応が始まることになる。
  [R3-2](rationale.md#r3-2)
- 「最後に普段どおり話した時刻」を前に出す。
  独居では誰も持っていない情報で、救急・病院で使われる。
  [救急救命士の視点]
- 携帯からの 119 は別の消防本部につながることがあり、転送される場合は電話を切らずに待つ。
  [消防庁「消防の動き」令和2年11月]

```
【救急カード】9:35
指令員の質問に答えるのが最優先です。
以下は答えるときのメモです。
1. 「救急です。場所は○○県○○市○丁目○番地（建物名・部屋番号）、目印は○○です」
2. 「私は離れた場所（○○市）から電話しています。家には母が一人で、いま家に誰もいません」
3. 「○○ ○○（78歳・女性）が、9時から3回、iPad のスピーカーの声かけに返事をしていません。最後に普段どおり話したのは8時40分「おはよう」です。呼吸や顔色は、誰も見ていません」
4. 「家の鍵は［施錠／キーボックス○○に合鍵／近所の○○さん（電話○○）が合鍵を持っています］」
5. 「私の名前は○○、この電話番号は○○。家の固定電話は○○です」
聞かれたら：生年月日 ○年○月○日／持病 ○○／かかりつけ ○○病院／普段の薬 ○○
つながった先が別の消防本部でも、電話を切らずに「○○市の件です」と言って転送を待ってください。
家に入った人へ：○○の引き出しにお薬手帳・マイナ保険証（資格確認書）・診察券があります。
```

- 本人の言葉からの L4（転んだ等）では、3 を「14:05 の声かけに『転んだ』と言い、その後の返事は○○です」に置き換え、「返事がない」の3段階は省く。
- カードは初期設定で指定した1名にだけ送る。
  家族グループには送らない。
  [R4-4](rationale.md#r4-4)

## 4. その場で電話をかける人向けの画面と補助の読み上げ（iPad）

- この画面は、iPad のホームにある「119 にかけるとき」ボタン1つから開く。
  L4 の発生中は自動で開く。
  読み上げボタンはこの画面の中にだけ置き、普段の画面には出さない。
  誤って開いた場合は、閉じるだけで何も送らない。
  [推測]
- 使う人の能力は「使える／使えない」の二値ではなく、段階で見る。
  介護の様式も、電話を使えるか（IADL）と、伝えられるか（意思の伝達）と、言う中身を持っているか（年齢・短期記憶・場所の理解）を別の項目で測る。
  電話の使用は「自分で番号を調べてかける／よく知った番号ならかける／出るがかけない／全く使わない」の4段階（Lawton の IADL 尺度）。
  伝達は認定調査「3-1 意思の伝達」の4段階。
  中身は認定調査「3-3 生年月日や年齢を言う」「3-4 短期記憶」「3-7 場所の理解」。
  [R2-5](rationale.md#r2-5)
- 読み上げが補うのは、電話はかけられるが、住所・年齢・時刻の並びを記憶から組み立てて言えない人。
  認知症では、計画を立て順序立てる力（実行機能）の障害が早期から出る一方、体で覚えた動作（手続き記憶）は進行しても長く保たれるので、「ボタンを押す」と「経過を説明する」は同じ負荷ではない。
  認知症でなくても、慌てて住所や電話番号が分からなくなることは 119 番通報一般で起きるとされる（東京消防庁）。
  家に来た家族・ヘルパー・近所の人は、番地・生年月日・時刻の並びをそもそも知らないことがある。
  [R2-5](rationale.md#r2-5)／救急救命士の視点
- 効かない人も正直に書く。
  自分から電話をかけられない人（IADL 電話の3〜4段階）や、意思の伝達がほとんどできない人には、通報者向けの補助は効かない。
  この層は、声で「家族に連絡して」と頼む流れ（基準 v2 3-5）と、無反応・転倒の L4 で家族に通知が飛ぶ流れが担う。
  本人向けに「家族を呼ぶ」ボタン1つを大きく置くのは、その追加案 [推測]。
- 住所・呼吸・顔色は通報者が自分の言葉で答えるのが基本で、iPad は iPad しか持っていない情報をふりがな付きの大きな字で出す。
  読んで自分の声で言うのを基本にし、それでも言えないときの予備として、各項目の横に「読み上げ」ボタンを置く。
  多少の重複があっても、伝わる手段を増やす方を取る。
  [杉浦の判断]
- 電話と iPad の2台を同時に扱う問題は、能力ではなく置き方の問題として扱う。
  電話をスピーカーにして iPad の印の上に置く（画面に描く）。
  [推測]
- 指令員が電話越しの合成音声をどう受け取るかは未検証である。
  実機で確認するまでは「検証中の補助機能」と位置づけ、発表で売りにしない。
  [推測]

```
手当ての指示が始まったら、iPad には触らず、指示に従ってください。
読み上げを使うときは、電話をスピーカーにして、この印の上に置いてください。
［全部読み上げ］（大きなボタン）：機械が住所から順に全部を読みます。押すだけで構いません。
①「救急です」
②住所：○○市○丁目○番地 ○○（建物名・部屋番号）目印：○○ 家の電話：○○　［読み上げ①］
③「○○さん、78歳女性。」（何が起きたかは、あなたが見た様子を自分の言葉で）　［読み上げ②］
④聞かれたら答える：いま呼吸しているか／顔色／冷や汗／話せるか（目で見て答える）
⑤【iPad の記録】最後に普段どおり話したのは 8:40。
 9:00・9:15・9:30 の声かけは返事なし　［読み上げ③］
⑥聞かれたら：持病 ○○／薬 ○○（お薬手帳は○○にある）／かかりつけ ○○病院　［読み上げ 予備］
読み終わったら「以上です」と言ってください。
```

- 読み上げボタンは、大きな「全部読み上げ」1つと、小さな項目別3つ＋予備1つ。
  「全部読み上げ」は画面の一番上に大きく置き、押すと住所→氏名・年齢・性別→経過→持病・薬・かかりつけの順に全部を読んで自動で止まる（約40秒、末尾に住所をもう一度）。
  慌てている人や認知症の人には、どの項目を押すべきかの判別が難しいので、大きなボタン1つで足りるようにする。
  多少指令員の質問と重なっても、正確な情報が伝わる価値の方が大きい。
  [杉浦の判断／秒数は推測]
  項目別のボタンは、どれを読ませるべきか判断して押せる人向けで、小さめでよい。
  項目別は画面の上から指令員が聞く順に並べ、番号を付ける。
  ①住所（都道府県から。建物名・部屋番号・目印・この家の固定電話番号まで）
  ②本人の氏名・年齢・性別（何が起きたかは含めない。その場の人が自分の言葉で言う）
  ③経過（最後に普段どおり話した時刻と、返事がなかった声かけの時刻）
  予備（画面の下に小さく）：持病・薬・かかりつけ（指令員に聞かれたときだけ押す）。
  「救急です」「何が起きたか」「呼吸・顔色」は機械に読ませない。
  [救急救命士の視点]
- 読み上げの動き。
  項目別のボタンは、1回押すとその項目だけを読んで自動で止まり、続けて次の項目は読まない。
  「全部読み上げ」は1回押すと順に全部を読んで自動で止まる。
  読んでいる途中でもう一度押すと止まる。
  長押し（押している間だけ読む）は代案で、慌てた人が止めるボタンを探せない点では有利だが、握力や手のふるえのある人には長押しが負荷になる。
  どちらも [推測] で、決めどころ（★）。
  各項目の音声は、機械自身が「機械の読み上げです。」と言ってから始める（人に前置きを言わせない）。
  読み終わったら、その場の人が「以上です」と言う、と画面に書く。
  [救急救命士の視点／推測]
- 読み上げの作り方。
  速さは通常の会話の7〜8割にし、文の間に1秒の間を置く。
  数字は一桁ずつ読む（7は「なな」、4は「よん」、0は「ゼロ」。「しち」「し」は使わない）。
  住所は都道府県から読み、丁目・番・号の区切りで間を置く。
  住所は2回読む（2回目の前に「もう一度言います。」）。
  氏名は姓と名の間を空け、続けて年齢・性別を読む。
  電話番号は 3-4-4 で区切る。
  固有名詞（氏名・建物名・地名）は初期設定で家族が入れた読み仮名で読む（7 節）。
  1項目は前置きを含めて10秒を目安にし、住所は書き取れる速さを優先して目安から外す。
  参考：火災通報装置の技術基準は「合成した女声」「発声が明瞭で語尾を明確に強調」「一区切り30秒以内」を求めている（[R2-5](rationale.md#r2-5)）。
  火災通報装置は装置単独で 119 に住所を流す仕組みで、人の通話に混ぜる本設計とは形が違う。
  [救急救命士の視点／推測]
- 指令員とのやりとり。
  指令員が「住所をもう一度」と言ったら、その場の人が①を押す。
  指令員が「○○市○丁目○番○号ですね？」と読み返したら、ボタンは押さず、その場の人が「はい」または「違います」と自分で言う。
  指令員が「呼吸をしていますか」「胸を押してください」と言い始めたら、iPad は置いて指令員の指示だけを聞く。
  それ以降は読み上げボタンを押さない。
  [救急救命士の視点]
- 指令員の声を iPad が聞き取って自動で答えることはしない。
  119 の通話でテストができず、指令員から見て誰が通報しているかが曖昧になるため（記事骨組み 第10章と同じ理由）。
- 持病・薬の表示と読み上げは、この画面と 5 節の表示を開いているときだけ使える（0 節「認証のある画面にだけ」の例外）。
  [推測]

★ 読み上げを残すか。
推奨：補助として残す。
画面表示を基本にし、電話はかけられるが住所・年齢・時刻の並びを組み立てて言えない人の予備として、項目別の読み上げボタンを置く。
理由：ボタンを押す動作と経過を説明する力は別の能力で、後者だけが落ちている人（認知症の早期、慌てた家族・近所の人）がいるから。
効かない層（自分から電話をかけられない・伝達がほとんどできない）は別の流れで受け、補助が効かないことを隠さない。
指令員の質問と重なる問題は、項目別のボタンで減らせるが、「全部読み上げ」では重なりを受け入れる（正確に伝わる方を取る）。
MVP では画面表示だけを作り、読み上げボタンは範囲外とする。
電話越しの聞き取りやすさを 119 以外の通話（家族の携帯）で試してから、実装するかを決める。

★ 読み上げの押し方。
推奨：1回押すと読んで自動で止まる（もう一度押すと止まる）。
「全部読み上げ」も項目別も同じ動き。
代案：押している間だけ読む。
どちらも実機で試すまで [推測] で、実装の都合で決めてよい。

## 5. 救急隊向けの表示（到着後、iPad の画面1枚と、1ボタンの読み上げ）

```
【救急隊の方へ】この画面は見守り AI の記録です。
        診断ではありません。
氏名：○○ ○○（○年○月○日生・78歳・女）
最後に普段どおり話した時刻：8:40「おはよう」
その後：9:00・9:15・9:30 スピーカーの声かけに返事なし（姿は見えていません）
家族：長女 ○○ 090-xxxx-xxxx（9:35 に通知済み・9:41 に家族が受け取り、119 番を依頼）
持病：○○／薬：○○（お薬手帳・マイナ保険証・診察券は○○の引き出し）
かかりつけ：○○病院（電話 ○○）
最後の食事：7:50 朝食の声かけに「食べた」と返答（食べたかは未確認）／最後の服薬の返答：昨夜
本人の意思表示（かかりつけ医の指示書）：［あり：○○に保管／なし］（家族が入力。AI は判断しない）
状況と、到着までの変化、行った手当は、あなたが伝えてください：＿＿＿＿
［救急隊に伝える］記録を約20秒で読み上げます。聞きながら、合っていれば「そのとおりです」、違えば付け足してください。
```

- 「直近3日の変化」「今日の記録」は2画面目。
  救急隊が読むのは 10〜20 秒なので1画面目は上の項目だけ。
  [救急救命士の視点]
- 読み上げは「救急隊に伝える」ボタン1つ。
  押すと、消防庁マニュアルの「救急車が来たら伝えること」の順（状況→到着までの変化→行った手当→持病・かかりつけ・薬・医師の指示）で、記録にある項目だけを約20秒で読み、自動で止まる。
  もう一度押すと途中で止まる。
  冒頭は機械自身が「見守り機器の記録です。診断ではありません。」と言う。
  [R3-1](rationale.md#r3-1)／推測
- 読み上げるのは記録にあること（最後に普段どおり話した時刻、返事なしの時系列、持病・薬・かかりつけ・指示書の所在）に限る。
  「状況」「到着までの変化」「行った手当」は機械が知らないので読まず、画面に「あなたが伝えてください」の欄を置く。
- 使い方は、その場の人が聞きながら「そのとおりです」と言うか、違う所を付け足すだけ。
  救急隊は観察や処置の手と目を患者から離さずに聞ける。
  その場の人が説明を組み立てる必要がなくなるので、健常者でも、痛みや動揺で話せないとき、経過を知らない近所の人のとき、に効く。
  マニュアル自身が「痛みにより会話が困難であり、情報を聴取することができない状況」を挙げている（マイナ救急の例）。
  [R3-1](rationale.md#r3-1)／推測
- 誤操作の対策は、ボタンを1つにし、この画面を L4 の発生中と 4 節の画面からの遷移でだけ出し、1回で自動停止すること。
  救急隊が既に聴取を終えている場合や周囲が騒がしい場合は、画面だけで足りる。
  救急隊が受話でなく対面で機械の声をどう受け取るかは未検証で、4 節と同じく「検証中の補助機能」とする。
  [推測]
- 「到着までの変化」は、L4 後の声かけへの返答として記録できた本人の言葉と時刻だけを載せる。

★ 救急隊向けの読み上げ。
推奨：1ボタンで付ける。
理由：伝える中身と順番はマニュアルに書かれていて、記録にある部分は機械の方が正確に言える。
その場の人は確認と補足に回れるので、認知症の本人にも、慌てた家族にも、経過を知らない近所の人にも効く。
処置中の邪魔になる懸念は、1ボタン・自動停止・表示条件で抑える。
MVP では 4 節と同じく画面表示のみを作り、読み上げは範囲外とする。

## 6. 受診用の記録（医師・ケアマネ面談）

家族が期間と項目を選び、本人への説明と同意、家族の承認の後に共有する。

- 語彙は認定調査の項目（食事摂取・上衣の着脱・薬の内服・しつこく同じ話をする・ひどい物忘れ・感情が不安定）と、ケアマネの課題分析標準項目（健康状態・ADL・IADL・認知機能や判断能力・生活リズム・排泄の状況・食事摂取の状況）に寄せる。

- 病名・評価票の項目番号・点数を書かない。
  「○○の可能性」は書かず、行動と回数と原文を並べる。
  [R4-3](rationale.md#r4-3)

  [ケアマネの視点]
