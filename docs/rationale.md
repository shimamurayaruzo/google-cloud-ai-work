回数・時刻・予定との照合・キーワードはコードで決める決定論の層、発話の意味は Gemini に「評価対象のデータ」として渡して確信度付きで返させる層、確信度が低いもの・医療的なもの・外部への共有は人に戻す層です。

## 1. 根拠の選び方

- 判定基準は「観察（何を見るか）」と「境界（いつ人に戻すか）」に分かれる。
- 観察の語彙は、ケアマネジャーと家族が日常で使う要介護認定の認定調査項目に合わせる。
- 認知機能の評価票は専門職が対面または家族への聞き取りで採点するもので、このエージェントは使わない。
- 境界は、消防庁の公開資料（救急車利用マニュアル、緊急度判定プロトコル）に合わせる。
- 診断は医師だけができる。
  エージェントは根拠（記録）を並べて「ご確認ください」で止める。
- 公的な基準や様式がある所はそれに合わせ、無い所は自分たちの初期値だと明示する。
  合わせたのは出力の形であって、判定の閾値や人に戻す境界の値は自分たちの初期値である。

<a id="r2-2"></a>
### 2-2 認知機能の評価票は使わない

認知機能の評価票（専門職が採点する尺度）は、項目の分割使用や専門職以外の採点が想定されていないため使わない。
- したがって、エージェントは評価票の項目番号・点数を出力しない。
  設問と同じ日常語（「着替え」「食事」「薬を決まった時間に決まった分量」「5 分前に聞いた話」）で記録を並べるに留め、採点は受け手の専門職に委ねる。

<a id="r2-3"></a>
### 2-3 対象者の位置づけ [初期値]（公的根拠なし・運用で見直す）

- 対象は、認知症高齢者の日常生活自立度Ⅱ相当（誰かが注意していれば日常生活が自立できる）で、独居または日中独居の方。
  要介護度の目安は要支援2〜要介護2、中心は要介護1。
- エージェントの声かけは「動作の見守り」ではなく「開始のきっかけ（促し）」で、認定調査の「見守り等」の定義にある「確認」「指示」「声かけ」に当たる。
- 自立度Ⅲ以上（声かけの理解が難しい）と自立度Ⅰ（促しが不要）は対象外。
- 根拠：ケアマネ視点の批評による見立て。
  認定基準時間との対応は未確認。

自立度Ⅱb の例示「服薬管理ができない，電話の応対や訪問者との対応など一人で留守番ができない等」（平成5年原通知）は電話を受ける側の例で、かける能力の喪失は書かれていない。
通知は「このランクは介護の必要度を示すものであり、認知症の程度の医学的判定とは必ずしも一致するものではない」「例示した症状等がすべての認知症高齢者に見られるわけではない」と明記している（平成18年改正版 p.2、2-5）。
したがって対象者をⅡ相当と置いても、電話や説明の能力は個人ごとに段階で見る。

用途：
- 通報者の能力を二値で扱わず、「電話をかけられるか」「伝達できるか」「年齢・時刻・場所を自分で言えるか」を別々に見る。
- 読み上げが補うのは「かけられるが、住所・年齢・時刻の並びを組み立てて言えない」層。
  認知症の早期（実行機能障害・語想起障害があり、言語理解と手続き記憶は保たれる）と、慌てた家族・近所の人がここに入る。
- 自分からかけられない・伝達がほとんどできない層には効かないと明記し、3-5 の声の依頼と L4 の通知で受ける。
- 対象者をⅡ相当と置いても、通知が「例示がすべてに見られるわけではない」と明記している以上、一律に「使えない」とは書かない。
- 読み上げの声質・区切りは火災通報装置の技術基準を参考にする。
  装置単独の通報と本設計は形が違うので、「指令台が機械の声に慣れている」とは言わない [初期値]（公的根拠なし・運用で見直す）。
- 火災通報装置の設置目的を「パニックで住所を言えないため」とする公的原文は見つからなかった。
  消防庁は「火災の発生を消防機関へ迅速かつ確実に通報するため」（令和6年7月9日 検討部会資料2）、京都市は「住所が分からなくても、…正確な住所を連絡することができます」と書く。
  この理由は設計の根拠に使わない。

- 遠隔の家族からの通報は「第三者通報・状況不明」に当たる。

### 4-4 個人情報と本人の同意 [確認]

  本人の依頼を外部へ出さないのは本人同意の原則による。
