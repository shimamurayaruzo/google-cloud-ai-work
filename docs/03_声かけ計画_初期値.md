## 2. 声かけ計画（初期値）

原則: 責めない言い方、1回の声かけで確認するのは1つ、返事がなければ少し置いてもう一度だけ、それでも取れなければ家族へ。時刻と言い回しは家族画面で変えられる。

### デイの日

| 時刻 | 声かけ（例） | 確認すること | 取れないとき |
|---|---|---|---|
| 8:00 | 「おはようございます。よく眠れましたか？」 | 起床、気分 | 8:15 に再度。無反応なら人感センサーを見て、8:30 に家族へ |
| 8:20 | 「今日はデイサービスの日です。9時にお迎えが来ます。お着替えは済みましたか？」 | 着替え（紙パンツを含む。呼び方は家族設定） | 8:35 に再確認 → 8:50 に家族へ |
| 8:45 | 「持ち物はかばんに入っていますか？」 | 持ち物 | 1回のみ。取れなくても家族へは「未確認」として夕方の要約に載せる |
| 9:00 | 「お迎えは来ましたか？」 | 出発 | 9:15 に再確認 → 9:30 に家族へ（お迎えが来ない可能性も含めて） |
| 9:30〜16:00 | 声かけなし（不在） | | 端末の生存監視のみ |
| 16:00 | 「おかえりなさい。今日はどうでしたか？」 | 帰宅、気分 | 16:20 に再確認 → 16:40 に家族へ |
| 16:30 | 「お茶を一杯どうですか？」 | 水分 | 1回のみ |
| 18:00 | 家族へ「今日の様子」を送信 | | |
| 19:00 | 「夕ご飯は食べましたか？」 | 夕食 | 19:30 に再確認。家族が在宅なら声かけを止める設定も可 |
| 21:00 | 「歯を磨いて、そろそろお休みしましょう」 | 歯磨き、就寝準備（夜の紙パンツ） | 21:20 に再確認。取れなくても夜は家族へ通知しない（翌朝の要約に載せる） |

### 時刻に関係なく

| きっかけ | 動き |
|---|---|
| 「痛い」「転んだ」「助けて」「苦しい」などの発話 | 即時に家族へ LINE。根拠の発話を添える。「確認した」が一定時間押されなければ段階上げ |
| 声かけに 2 回続けて無反応 | 人感センサーが別室で反応していれば異常としない。反応がなければ家族へ |
| 端末の生存信号が途切れる | 家族へ「端末が応答していません」 |
| 本人が「電話して」と頼む | 外へはかけず、家族へ「こう頼まれました」と伝える |

## 3. 決まっていないこと（家族に確認）

- デイサービスの曜日: 火・水 か、火・金 か
- 服薬の有無と時刻（あれば声かけに入れる）
- 家族が家を出る時刻と帰る時刻（在宅中は声かけを止めるか、続けるか）
- 週末の扱い（平日と同じ計画か、家族在宅で止めるか）
- デイ以外の日の昼食（用意して置いてあるか、本人が作るか）
- 紙パンツの呼び方（家族が使っている言い方をそのまま設定する）

## 4. 再生モードの台本（デイの日の例）

```
08:00  AI「おはようございます。よく眠れましたか？」
08:00  母「うん、まあまあ」                         → 起床・気分: 普通
08:20  AI「今日はデイサービスの日です。9時にお迎えが来ます。お着替えは済みましたか？」
08:20  母「まだ」                                   → 8:35 に再確認と決める
08:35  AI「そろそろお着替えどうですか？」
08:35  母「着替えたよ」                             → 着替え: 済み
09:00  AI「お迎えは来ましたか？」
09:02  母「来たよ、行ってきます」                    → 出発: 済み。家族へ「準備完了、出発」
16:00  AI「おかえりなさい。今日はどうでしたか？」
16:00  母「疲れた。腰がちょっと痛い」                → 帰宅: 済み。「痛い」を検知 → 家族へ根拠付き通知
16:30  AI「お茶を一杯どうですか？」
16:30  （返事なし）                                 → 人感センサー: 居間で反応あり → 異常としない
18:00  家族へ「今日の様子」
       「8:35 に着替えを確認、9:02 にデイへ出発。16:00 に帰宅、腰の痛みの訴えあり（通知済み）。
        16:30 の声かけには返事がありませんでしたが、居間で動きがありました。
        最近 3 日と比べて、質問の繰り返しは増えていません。」
19:00  AI「夕ご飯は食べましたか？」
19:05  母「食べた」                                 → 夕食: 済み
21:00  AI「歯を磨いて、そろそろお休みしましょう」
21:00  母「はい、おやすみ」                          → 就寝準備: 済み
```
