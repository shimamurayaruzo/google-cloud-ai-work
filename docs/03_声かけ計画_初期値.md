## 2. 声かけ計画（初期値）

原則: 責めない言い方、1回の声かけで確認するのは1つ、返事がなければ少し置いてもう一度だけ、それでも取れなければ家族へ。時刻と言い回しは家族画面で変えられる。

家族が決めた言葉: 紙パンツは家で「おむつ」と呼んでいるので、声かけでも「おむつ」を使う。薬は決めた場所（黒い机の上）に置き、本人が自分で飲む。「何の薬？」と聞かれたら「脳の薬ですよ」、「どこにある？」と聞かれたら「黒い机の上にありますよ」と答える（それ以上の説明はしない）。

朝の順番は、①おむつの交換 → ②歯磨き → ③顔を洗う。1回の声かけに1つずつ。

### 時刻に関係なく

| きっかけ | 動き |
|---|---|
| 「痛い」「転んだ」「助けて」「苦しい」などの発話 | 即時に家族へ LINE。根拠の発話を添える。「確認した」が一定時間押されなければ段階上げ |
| 声かけに 2 回続けて無反応 | 人感センサーが別室で反応していれば異常としない。反応がなければ家族へ |
| 端末の生存信号が途切れる | 家族へ「端末が応答していません」 |
| 本人が「電話して」と頼む | 外へはかけず、家族へ「こう頼まれました」と伝える |

## 3. 決まったこと・決まっていないこと

決まったこと（2026-09-26 家族の回答）: デイは火・金。薬は夕食後に 2 錠、聞かれたら「脳の薬」。週末は平日と同じ。昼食は家族が用意し 12:00 に統一。紙パンツは「おむつ」と呼ぶ。朝は おむつ交換 → 歯磨き → 洗顔 の順。

決まっていないこと:
- 家族が家を出る時刻と帰る時刻（今は考えない、と家族の判断。在宅中も声かけは続ける前提で作る）
- （服薬は決着: 黒い机の上に置き、本人が自分で飲む）

## 4. 再生モードの台本（デイの日の例）

```
08:00  AI「おはようございます。よく眠れましたか？」
08:00  母「うん、まあまあ」                         → 起床・気分: 普通
08:05  AI「まず、おむつを新しいのに替えましょうか」
08:05  母「うん、替えた」                           → おむつ: 済み
08:15  AI「歯を磨きましょう」
08:15  母「はいはい」                               → 歯磨き: 済み（自己申告）
08:25  AI「顔を洗ってさっぱりしましょう」
08:25  （返事なし）                                 → 8:40 に再確認と決める
08:35  AI「今日はデイサービスの日です。9時にお迎えが来ます。お着替えは済みましたか？」
08:35  母「まだ」                                   → 8:45 に再確認と決める
08:40  AI「お顔、洗えましたか？」
08:40  母「洗ったよ」                               → 洗顔: 済み
08:45  AI「そろそろお着替えどうですか？」
08:45  母「着替えたよ」                             → 着替え: 済み
09:00  AI「お迎えは来ましたか？」
09:02  母「来たよ、行ってきます」                    → 出発: 済み。家族へ「準備完了、出発」
16:00  AI「おかえりなさい。今日はどうでしたか？」
16:00  母「疲れた。腰がちょっと痛い」                → 帰宅: 済み。「痛い」を検知 → 家族へ根拠付き通知
16:30  AI「お茶を一杯どうですか？」
16:30  （返事なし）                                 → 人感センサー: 居間で反応あり → 異常としない
18:00  家族へ「今日の様子」
       「8:35 に着替えを確認、9:02 にデイへ出発。16:00 に帰宅、腰の痛みの訴えあり（通知済み）。
        16:30 の声かけには返事がありませんでしたが、居間で動きがありました。
        最近 3 日と比べて、質問の繰り返しは増えていません。」
19:00  AI「夕ご飯は食べましたか？」
19:05  母「食べた」                                 → 夕食: 済み
19:40  AI「ご飯のあとのお薬を飲みましょう。黒い机の上に 2 錠あります」
19:40  母「何の薬？」
19:40  AI「脳の薬ですよ。黒い机の上にありますよ」
19:43  母「飲んだよ」                               → 服薬: 済み
21:00  AI「歯を磨いて、そろそろお休みしましょう」
21:00  母「はい、おやすみ」                          → 就寝準備: 済み
```
