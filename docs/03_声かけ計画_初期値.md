## 2. 声かけ計画（初期値）

原則: 責めない言い方、1回の声かけで確認するのは1つ、返事がなければ少し置いてもう一度だけ、それでも取れなければ家族へ。時刻と言い回しは家族画面で変えられる。

家族が決めた言葉: 紙パンツは家で「おむつ」と呼んでいるので、声かけでも「おむつ」を使う。薬は決めた場所（黒い机の上）に置き、本人が自分で飲む。「何の薬？」と聞かれたら「脳の薬ですよ」、「どこにある？」と聞かれたら「黒い机の上にありますよ」と答える（それ以上の説明はしない）。

朝の順番は、①おむつの交換 → ②歯磨き → ③顔を洗う。1回の声かけに1つずつ。

## 5. 朝の流れ（2026-10-14 変更）

きっかけ（2026-10-14 水、家族の報告）: 8:00 に起床の声かけ → 母は起きず返事なし → 60 秒で「返事なし」扱い → 8:05 に時刻どおり「おむつを新しいのに替えましょうか」が出た（起きていないのに）→ 8:15 歯磨き… と、計画の時刻で機械的に進んでしまった。

そこで朝は「時刻で出す」をやめ、**本人の返事があってから次へ進む順番の流れ**にする（設定 `policy.morning`、実装 `src/state/morning.ts`）。

| 工程 | 声かけ | 項目 | 次へ進む条件 | 返事が取れないとき |
|---|---|---|---|---|
| ① 起こす | 名前を呼び、緊迫感のある言い方を順に（下の 3 つ）。名前は `person.wakeName`（無ければ `callName`） | greeting | 「**起きた**」の返事（下の「工程①への返事の 3 種類」） | **1 分おき**に繰り返す（最大 60 回 = 60 分）。「起きたくない」・判定できない返事も同じ |
| ② おむつ | 「おむつやパンツは濡れていませんか？ 新しいのに替えましょうか」 | diaper | 済み（done） | 「まだ」等（not_yet）は **2 分後**に確認の言い回し、返事なし・判定できないは **5 分後**に同じ声かけ（合わせて最大 6 回） |
| ③ 洗顔・歯磨き | 「顔を洗って、歯を磨きましょうね」 | face（済みなら teeth も済み） | 済み | 同上 |
| ④ 着替え | デイの日「今日はデイサービスで出かける日ですよ。9 時にお迎えが来ます。お着替えをしましょう」／それ以外「お着替えをしましょうか」 | dress | 済み → 朝の流れは完了 | 同上 |

起こす声かけ（既定。1 回目から順に使い、3 回目の次は 1 回目に戻る。`policy.morning.wakeTexts` で家族が変えられる。`{name}` は呼ぶ名前、`{hour}` はその時刻の「時」）:

1. 「{name}！ おはようございます。朝の {hour} 時です。起きてください」
2. 「{name}、起きてください。朝ですよ」
3. 「{name}！ 聞こえますか。起きる時間です」

②〜④はこれまでどおり穏やかな言い方。

### 工程①（起こす）への返事の 3 種類（2026-10-14 夜の家族の要望）

それまでは「どんな返事でも起きたとみなす」だったが、「起きたくない」でも次へ進んでしまうので、返事を 3 種類に分ける。**規則だけで決める**（LLM の分類は使わない。`classifyWakeReply`、`src/state/morning.ts`）。部分一致で、**体調が悪い → 起きたくない → 起きた** の順に見る（「起きたくない」は「起きた」を含むため）。

| 種類 | 語（部分一致。初期値） | 工程 | 本人への一言 | 家族へ | 起こす声かけ |
|---|---|---|---|---|---|
| 起きた | 起きた・起きてる・起きます・起きる・はい・うん・ええ・おはよう・分かった・了解 | 工程②へ | 「おはようございます。」（会話ターンが済みと判定したときはその一言） | なし | 終わる |
| 起きたくない／まだ寝たい | 起きたくない・起きない・起きられない・まだ・寝かせて・寝たい・眠い・疲れた・いや・嫌・ううん・いいえ・あとで・待って・もう少し・うるさい | 工程①のまま | **「がんばって起きてください。それとも体調が悪いのですか？」**（`policy.morning.refuseSay` で変えられる） | なし（上限 60 回で今までどおり check 1 回） | **1 分おきに続ける**（回数は数え続ける） |
| 体調が悪い | 体調が悪い・具合が悪い・気分が悪い・気持ち悪い・調子が悪い・しんどい・だるい・頭が痛い・痛い・熱がある・吐き気。痛みの言葉・L4 の語（rules の `detectPain` / `detectL4`）もここ | 工程①で朝の流れを終える（`cutoff`。残りは夕方の要約に「未確認」） | **「分かりました。無理をしないで、横になっていてください」**（家族に知らせたことは本人に言わない） | check「起こしの声かけに『体調が悪い』とのお返事です」を 1 回。痛み・L4 の語のときは会話ターンの check（痛み）／ urgent（至急）だけで、重ねない | **止める** |

- 上のどれでもない返事（テレビ・ラジオの印、ニュースの口調、判定できない言葉）は、起きたとはみなさず、返事なしと同じく 1 分おきに起こし続ける。一言は言わない。
- 返事なし（no_answer）は今までどおり 1 分おきに繰り返し、`wakeMaxRepeats`（60）回で家族へ check 1 回、その後は待つ。
- 会話ターンの記録（判定）も揃える: 起きた → done、起きたくない・体調が悪い → not_yet、どれでもない → unclear。台帳の `morning_step` の args に `wake`（awake / refuse / unwell / none / no_answer）を残す。体調が悪いで終えたときの `morning_finished` は `why: "unwell"`。

### 工程②〜④で「まだ」のとき（2026-10-14 夜のテストで判明）

「まだ」「今から替える」「着替えます」のような返事（not_yet）に 5 分後に同じ声かけを繰り返すだけだと、本人には止まったように感じられた。そこで:

- 本人への一言は **「では、できたら教えてくださいね」**（`policy.morning.notYetSay` で変えられる）。
- 次の声かけは **`stepFollowupMinutes`（既定 2）分後**に、工程ごとの**確認の言い回し**で出す（`policy.morning.followupTexts` で項目ごとに変えられる）:
  - ② 「おむつは替えられましたか？」 ③ 「お顔と歯磨きはできましたか？」 ④ 「お着替えはできましたか？」
- 返事なし（no_answer）・判定できない返事のときは、今までどおり `stepRepeatMinutes`（5）分後に元の声かけ。
- 繰り返しの数え方と上限（`stepMaxRepeats` = 6 回で家族へ check 1 回）は変えない（確認の言い回しも 1 回と数える）。
- 「今から替える」「これから洗います」「着替えます」のような「これからする」の言い方は、会話ターンが済み・判定できないとしても not_yet に揃える（「〜た」「ました」「済んだ」があれば揃えない）。

決まり:

- 朝の流れの時間帯（既定 8:00〜10:30）は、計画の **起床・おむつ・歯磨き・洗顔・着替え・持ち物** の時刻ベースの声かけを作らない（朝の流れが代わりに出す。持ち物は朝の流れに含めない）。お迎え（9:00）・昼・夕・水分などはこれまでどおり時刻で出す。
- 上限まで返事が取れなければ、家族へ**確認のお願い（check）を 1 回だけ**送り、その工程で**待ち続ける**（勝手に次へ進まない）。家族がその通知を「確認した」にしたら、同じ工程の声かけをもう一度始める（同じ工程でお願いを重ねることはしない）。
- **10:30 を過ぎたら**朝の流れを終える。デイの日は **9:00 の「お迎えは来ましたか？」を時刻どおりに出し、その時点で朝の流れを終える**。残りの工程は夕方の「今日の様子」の「気になったこと」に「未確認」として載せる。
- 朝の流れの繰り返しは、起こすための繰り返しであって無反応の異常検知ではないので、基準 v2 の「返事なし 3 回」の段階表（L3/L4）の**対象外**。至急にはならず、無反応の回数（`signals.noAnswerCount`）にも数えない。ただし「転んだ」「助けて」などの L4 の語・痛みの言葉はいつもどおり。
- 寝室モードのときだけ動く（お風呂モード・就寝時間帯・L4 モード・停止中は出さない）。

設定（既定。未設定の世帯もこの値で有効）:

```
policy.morning = { enabled: true, startTime: "08:00", endTime: "10:30",
                   wakeRepeatMinutes: 1, wakeMaxRepeats: 60, stepRepeatMinutes: 5, stepMaxRepeats: 6,
                   stepFollowupMinutes: 2,
                   wakeTexts?: string[],
                   refuseSay?: string,      // 既定「がんばって起きてください。それとも体調が悪いのですか？」
                   notYetSay?: string,      // 既定「では、できたら教えてくださいね」
                   followupTexts?: { diaper?: string, face?: string, dress?: string } }
```

`enabled: false` にすると、§2 の表どおりの時刻ベースの声かけに戻る。台帳には `morning_step`（args: step, task, result。工程①は wake、②〜④の not_yet は awaitingDone も）と `morning_finished`（args: result, step, remaining）を残す。

再生モードの台本では、ステップに `"morning": true` を書くと、朝の流れのいまの工程の声かけに返事したことになる（`task` は省ける。例 `eval/scenarios/morning.json`）。
