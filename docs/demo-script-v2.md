# 3 分デモ動画 台本 v2（2026-10-07 島村＋Claude。初版は杉浦 docs/demo-script.md）

初版からの変更: 起動モード 2 つ（寝室／お風呂）を入れた。「腰が痛い」は至急ではなく確認のお願い（基準 v2）。無反応 3 回の至急と「確認した」で止まる流れを入れた。自己修復は 15 秒に縮めた。絵本・将来連携・注入防御の実演は入れない（記事で触れる）。

作り方: 画面は Playwright で自動録画（`scripts/video/`）、ナレーションは Cloud Text-to-Speech（ja-JP-Chirp3-HD、声は島村さんの聞き比べで決定）、結合は ffmpeg。実写 2 カット（母の後ろ姿、脱衣所の iPad）だけ島村さんがスマホで撮る。字幕は付けない（各カットの見出しだけ）。競合の名前は出さない。数字は「15 分後」以外は画面に出す。

尺: 180 秒。公開は YouTube 限定公開（可否は公式に確認済みの前提。NG なら公開に切替）。
