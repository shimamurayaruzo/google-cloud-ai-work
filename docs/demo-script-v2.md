# 3 分デモ動画 台本 v2（2026-10-07 島村＋Claude。初版は杉浦 docs/demo-script.md）

初版からの変更: 起動モード 2 つ（寝室／お風呂）を入れた。「腰が痛い」は至急ではなく確認のお願い（基準 v2）。無反応 3 回の至急と「確認した」で止まる流れを入れた。自己修復は 15 秒に縮めた。絵本・将来連携・注入防御の実演は入れない（記事で触れる）。

作り方: 画面は Playwright で自動録画（`scripts/video/`）、ナレーションは Cloud Text-to-Speech（ja-JP-Chirp3-HD、声は島村さんの聞き比べで決定）、結合は ffmpeg。実写 2 カット（母の後ろ姿、脱衣所の iPad）だけ島村さんがスマホで撮る。字幕は付けない（各カットの見出しだけ）。競合の名前は出さない。数字は画面に出し、ナレーションでは「15 分後」「10 分後」のような分数を言わない（2026-10-14）。

尺: 180 秒。公開は YouTube 限定公開（可否は公式に確認済みの前提。NG なら公開に切替）。

## 仮組み 2 回目（2026-10-14）で分かったこと

製品の変更（朝の流れ、お風呂の 歯磨き → 体を洗う → 出る）に合わせて c03・c05 を撮り直した。`npm run video` で tmp/video/demo-draft.mp4（180 秒）。

- 尺: c05 の新しいナレーション（20.2 秒、前後の間込みで 20.9 秒）が 20 秒に入らないため、c03 を 1 秒縮めて c05 に回した（c03 24–49、c04 49–65、c05 65–86）。全体は 180 秒のまま。
- c03: デモ世帯の `person.wakeName` を「お母さん」にした（src/seed/household.ts の demoHousehold）。8:00 の 1 回目に返事が無いと、本人には「また声をかけますね。」と出る（規則の一言）。1 分後の 2 回目は言い方が変わる。洗顔の声かけで録画を終え、洗顔・着替えの返事は録画の外で済ませて朝の流れを終えている（c04 の 8:52 に朝の流れの声かけが割り込まないように）。
- c05: 実写 B は 2 秒に縮めた（撮るのは 5 秒のままで、頭から 2 秒を使う）。歯磨きは区間を分けて一瞬だけ映し、返事はしていない（歯磨きの「返事なし」が夕方の要約に残らないように）。
- c05 で見つかった製品側の問題: 「体を洗う」のお知らせ（info）が未確認のままだと、「お風呂を出た」が同じ通知とみなされて送られない（src/notify の重複判定は level・origin・task が同じなら同じ通知。お知らせは「確認した」を押す場所も無い）。録画では「体を洗う」を確認済みにしてから「出ませんか」に進めている（scenes.json の ackNotice。製品が直ったら外す）。このため c05 の最後の家族画面では「体を洗う」が薄く表示される。
- 家族画面の記録と夕方の要約で、「出ませんか」への返事が「お風呂（体を洗う）」と表示される（項目名が bath 1 つのため）。
- c06・c07・c09 は朝の流れの時間帯（8:00〜10:30）の外なので影響なし。c09 の要約の「お返事の記録」に朝の流れの返事（起きたよ・替えたよ・洗ったよ・着替えたよ）とお風呂の返事 2 件が並ぶ。
- 録画の道具: サーバーの死活確認を /healthz から /ping に（10/6 の変更に追従）。poll に ms、waitText に poll: true（出るまで取り出しを繰り返す）、ackNotice を足した。
- 実写（c02・c05 の板）は今までどおりプレースホルダ。
