見張らない見守り

予定と返答で次の声かけを変える、在宅介護の見守りエージェントです。

このページは開発用の入口です。馬場さんの本画面（顔画面・家族画面）ができたら、ここと /device・/family はそれに置き換わります。

  • /device 顔画面（iPad）本画面が無い間は開発者向け確認ページを出します
  • /family 家族の画面合言葉でログインします。本画面が無い間は開発者向け確認ページを出します
  • /dev/device.html 開発者向け: 端末の確認ページ生存信号、声かけの読み上げ、返事の送信
  • /dev/family.html 開発者向け: 家族 API の確認ページ今日の様子、計画、承認、台帳、設定、停止、再生モード
  • /healthz 死活確認{ "ok": true } を返します
